# AI-in-histopathology-for-Breast-Cancer-classification
📌 Project Overview
- This project leverages Artificial Intelligence and Machine Learning to assist in histopathological image analysis, specifically focusing on classifying normal and abnormal tissues.
- The model aims to support pathologists in early disease detection and diagnosis by analyzing high-resolution microscopic images.

🎯 Objective
- To develop an AI-driven model capable of differentiating between normal and abnormal tissue samples from histopathological images with high accuracy, helping streamline pathology workflows and improve diagnostic precision.

🧪 Dataset
- Collected from Nanavati Hospital, Mumbai, under expert supervision.

- Includes labeled high-resolution histopathology images of normal and abnormal tissues.

- Ethical compliance and patient anonymity were maintained.

🛠️ Tools & Technologies
- Python, NumPy, Pandas, OpenCV

- TensorFlow / Keras or PyTorch for deep learning

- Scikit-learn for preprocessing and traditional ML models

- Matplotlib / Seaborn for visualization

- Jupyter Notebook for experimentation

⚙️ Methodology
- Data Collection & Annotation

- Preprocessing (resizing, normalization, augmentation)

- Model Building – CNN architecture for image classification

- Training & Evaluation – Accuracy, Precision, Recall, F1 Score

- Visualization – Confusion matrix, ROC curve, sample predictions

📈 Results
- Achieved over 95% accuracy in differentiating abnormal from normal tissue samples.

- The model shows potential for assisting medical professionals in preliminary screening.

🧠 Key Learnings
- Gained practical experience in medical image analysis using AI

- Understood the challenges of working with imbalanced and high-dimensional medical data

- Learned the importance of ethical handling of sensitive medical datasets
